About Generative Art

Geometric Shapes: Uses Object-Oriented Programming with Shape, Circle, Square, and Triangle classes. Each shape is randomly positioned with colors from the selected palette.

Fractal Tree: Generates a recursive tree where each branch splits into two smaller branches. The depth parameter controls complexity.

Spiral Pattern: Creates a spiral pattern with colored circles arranged according to mathematical functions.
