🤖 About Neural Style Transfer (ML Component)

Style transfer is a machine learning technique that applies the artistic style of one image to the content of another. This implementation uses OpenCV's DNN module with artistic filters to recreate famous painting styles.

Available Artist Styles

🌻 Van Gogh

Bold, expressive brushstrokes with vibrant, swirling colors. Known for "Starry Night" and sunflower paintings.

🎨 Monet

Soft, dreamy impressionist style with delicate color blending. Master of light and water reflections.

🔷 Picasso

Abstract cubist approach with geometric shapes and fragmented perspectives. Revolutionary modern art style.

🌊 Munch

Dramatic, emotionally intense style with bold contrasts. Famous for "The Scream" and expressive techniques.

🎭 Kandinsky

Abstract geometric compositions with vibrant colors. Pioneer of abstract art movement.

How It Works

  • Content Extraction: Analyzes the structure and objects in your image
  • Style Application: Applies artistic filters mimicking painter techniques
  • Image Synthesis: Combines content with style using OpenCV algorithms
  • Color Enhancement: Adjusts saturation, contrast, and tone

Technologies Used

  • OpenCV DNN: Deep Neural Network module for image processing
  • Stylization Filters: cv2.stylization() for artistic effects
  • Edge Preservation: Maintains important image features
  • Color Enhancement: CLAHE (Contrast Limited Adaptive Histogram Equalization)

Note: This is a lightweight implementation using OpenCV's artistic filters. For full neural style transfer, advanced models like VGG19 with TensorFlow/PyTorch would be used, but require significant computational resources.

Max file size: 16 MB | Supported formats: JPEG, PNG, BMP | Output resolution: 800x600 pixels
