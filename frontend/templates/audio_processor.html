🌌 Generate Ambient Soundscape

Create an original ambient drone soundscape using synthesized harmonic layers

🎵 About Audio Processing

This module uses PyDub for audio manipulation and Librosa for advanced processing and visualization.

⚡ Speed & Pitch Effects

  • Speed Up: Increases playback speed by 1.5x using speedup effect
  • Slow Down: Decreases speed to 0.75x by changing frame rate
  • Pitch Up: Shifts pitch +4 semitones using librosa.effects.pitch_shift
  • Pitch Down: Shifts pitch -4 semitones

🎚️ Spatial Effects

  • Echo: Delayed copy with 300ms delay and 0.5 decay factor, multiple repetitions
  • Reverb: Simulates room acoustics with multiple delayed copies at 50-300ms intervals

🎛️ Audio Filters

  • Low Pass Filter: Removes frequencies above 1000Hz (muffled sound)
  • High Pass Filter: Removes frequencies below 1000Hz (thin, tinny sound)
  • Bass Boost: Amplifies low frequencies below 300Hz by +5dB

🌌 Ambient Soundscape Generator

Generates an original ambient drone using multiple harmonic layers (A2, E3, A3, E4, A4 frequencies), slow amplitude modulation at 0.1Hz, and ambient noise texture.

📊 Spectrogram Visualization

Uses librosa's Short-Time Fourier Transform (STFT) to visualize frequency content over time.

Technologies: PyDub for audio manipulation, Librosa for pitch shifting and spectral analysis, NumPy for sound synthesis, SoundFile for WAV operations.

Max file size: 50 MB | Supported formats: MP3, WAV, OGG, FLAC, M4A | Output format: MP3 (320kbps)
