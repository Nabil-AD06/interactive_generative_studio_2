About This Project

This interactive studio demonstrates the power of Python for digital creativity. It combines generative art, data processing, image manipulation, audio transformation, and machine learning in an intuitive web interface built with Flask.

🚀 Technologies: Object-Oriented Programming (OOP), generative algorithms, artistic data visualization, 25+ image filters with OpenCV, audio processing with PyDub/Librosa, neural style transfer with OpenCV DNN, and web development with Flask.

Python Flask OpenCV PIL Matplotlib PyDub Librosa NumPy
