Audio Processing Unavailable

The audio processing module requires additional Python libraries that are not currently installed.

📦 Required Libraries

To enable audio processing features, please install the following packages:

pip install pydub
pip install librosa
pip install soundfile
pip install ffmpeg-python

Note: FFmpeg must also be installed on your system:

  • Ubuntu/Debian: sudo apt-get install ffmpeg
  • macOS: brew install ffmpeg
  • Windows: Download from ffmpeg.org

⚠️ What's Missing?

  • PyDub: Audio file manipulation (speed, pitch, effects)
  • Librosa: Advanced audio analysis and pitch shifting
  • SoundFile: Reading and writing audio files
  • FFmpeg: Audio codec support for multiple formats

✨ Available Audio Features (Once Installed)

  • Speed up / slow down audio playback
  • Pitch shifting (+/- semitones)
  • Echo and reverb effects
  • Audio filters (lowpass, highpass, bass boost)
  • Ambient soundscape generation
  • Spectrogram visualization
  • Audio layering and mixing

💡 Quick Installation Guide

  1. Open your terminal/command prompt
  2. Navigate to your project directory
  3. Run: pip install pydub librosa soundfile ffmpeg-python
  4. Install FFmpeg for your operating system (see instructions above)
  5. Restart the Flask application
  6. Refresh this page - audio features should now be available!

Having trouble installing? Check the PyDub documentation or Librosa installation guide.
